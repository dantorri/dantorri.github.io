My part of the robot

For our senior design project, I designed and integrated RF and Wi-Fi communications for a robot intended to operate across land and water. I investigated low-frequency RF, antenna placement, and electromagnetic interference as part of the telemetry problem.

The embedded control work also includes an ESP32 interface for the left and right drivetrain, the arm motor, and the front arm wheel. A laptop sends a sequence once; the firmware executes the timing locally.

That distinction matters on a moving robot: the computer describes the sequence, while the microcontroller owns the motor-command timing.

The underwater RF investigation

Making the controls explicit

The sequence controller treats each motor command as a signed throttle request, with ramping and explicit arming. Each step sets all four motor targets, including the motors that should be at zero. The implementation includes stop and emergency-stop commands.

This is timed command execution. It does not measure arm angle or contact force, and a zero output does not guarantee that the arm holds position. Those limits shape what a test can demonstrate.

Taking the mechanism into simulation

A separate follow-on study uses the Fusion CAD assembly to build a MuJoCo environment for land-based obstacle traversal. The question is whether a learned policy can coordinate the drivetrain, front arm, and arm wheel to negotiate curbs.

The environment includes actuator envelopes, command latency, sensor-based observations, and dynamics randomization. PPO and SAC policies are compared with scripted wheel-only and arm-assist references, using separate validation and held-out evaluation seeds.

I evaluate policies across curb heights and randomized physics, using sensor observations intended to reflect inputs available on the robot.

Simulation scope. This is a research simulator, not a hardware-validated digital twin. It does not model aquatic dynamics. The learned policies have not been deployed on the physical robot, and the model has not been calibrated from hardware logs.
